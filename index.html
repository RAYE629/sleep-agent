A FEW THINGS TO KNOW.

关于 Sleep Agent

第一版包含哪些功能？

第一版设计包含语音唤醒与对话、体动与温度采集、预设音频播放、暖灯控制、定时渐亮唤醒，以及手机端设置与曲线查看。体验设计还加入梦境记录与智能体释梦、日程记录与提醒。当前为课程原型研发阶段，本页面介绍设计方案，不代表全部功能已完成。

需要每晚拿起手机操作吗？

按设计，音乐、音量、灯光和唤醒时间提前在手机端设置。躺下后可通过语音对话，同意后播放预设内容，也可要求停止播放或关灯。

它能判断深睡、治疗失眠吗？

不能。第一版的体动与温度数据不直接作为睡眠分期或失眠结论。Sleep Agent 是生活陪伴产品原型，不提供医疗诊断或治疗。

脑电、香氛与温控会加入吗？

这些属于探索方向，将根据设备、成本与技术验证结果决定是否接入，不作为第一版已具备的能力展示。
